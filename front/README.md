# Front-end Angular

Application Angular 14 du projet Yoga App.

## Commandes utiles

Installer les dépendances :

```bash
npm ci
```

Lancer le front :

```bash
npm start
```

Lancer les tests Jest avec couverture :

```bash
npm test
```

Lancer les tests end-to-end Cypress :

```bash
npm run e2e:ci
```

Voir le README racine pour le lancement complet avec back-end, base MySQL et URLs.
